# LingNote - Global UI Skill

## 1. UI 总体目标

LingNote 的 UI 必须呈现出一种“现代、克制、轻盈、安静、可信”的气质。

它不是企业后台，不是低质 SaaS 套壳，不是花哨的设计展示页，也不是信息堆满的工具面板。

它应当像一个精致的个人知识空间：
- 内容是主角
- 界面只是容器
- 交互是顺滑的
- 视觉是轻的
- 层次是清晰的
- 体验是高级但不过度炫技

所有页面都必须围绕这个目标构建。

---

## 2. 设计原则

### 2.1 内容优先
页面的第一职责是承载内容，而不是展示装饰。

- 笔记内容、标题、摘要、标签、操作区的可读性优先于视觉花样
- 信息层级必须清晰
- 页面留白要足够
- 不允许用复杂装饰抢夺内容注意力

### 2.2 克制高级
UI 风格必须简洁，但不能廉价。

- 少即是多
- 精致但不堆叠
- 轻阴影、轻边框、柔和圆角
- 统一的间距与节奏
- 不使用刺眼高饱和色
- 不使用廉价渐变和霓虹效果

### 2.3 统一性优先
所有页面、组件、弹窗、按钮、输入框、卡片的视觉规则必须统一。

- 不同页面不能像来自不同产品
- 不同组件不能有不同圆角、阴影、字体风格
- 统一设计语言必须始终保持

### 2.4 轻交互
动画必须服务于理解与反馈，不得喧宾夺主。

- 只允许短、柔、自然的动画
- 动画必须增强状态变化的可感知性
- 禁止夸张弹跳、过度缩放、炫技转场
- 所有动画时长应保持克制

---

## 3. 颜色系统

### 3.1 全局背景
整个应用背景必须是极浅灰白，而不是纯白。

推荐：
- `#F5F7FA`
- `#F7F8FC`

目的：
- 避免纯白刺眼
- 营造高级纸张感
- 提供柔和层次

禁止：
- 大面积 `#FFFFFF` 纯白铺满全屏

### 3.2 主强调色
主强调色必须低饱和，统一且克制。

推荐：
- 冷静科技蓝：`#4F7CFF`
- 备用微青蓝：`#5B8DEF`

hover / active 需要有细微变化：
- hover：略深
- active：再略深一点

禁止：
- `#1890FF`
- `#00BFFF`
- `#FF0000`
- `#00FF00`

这些颜色容易显得像旧后台系统。

### 3.3 文本颜色
文本颜色必须清晰但不生硬。

主文本：
- `#1F2937`

次文本：
- `#6B7280`

弱辅助文本：
- `#9CA3AF`

禁止：
- 大面积纯黑 `#000000`

### 3.4 边框颜色
边框必须极浅、低存在感。

推荐：
- `#E5E7EB`
- `rgba(15, 23, 42, 0.06)`

禁止：
- 粗黑边框
- 高对比边框
- 强烈描边感

### 3.5 卡片背景
卡片背景应略高于全局背景。

推荐：
- `#FFFFFF`

配合：
- 轻阴影
- 浅边框
- 柔和圆角

### 3.6 状态色
状态色必须低饱和。

Success：
- `#22C55E`

Warning：
- `#F59E0B`

Error：
- `#EF4444`

禁止大面积高饱和状态色铺满界面。

---

## 4. 材质与层次

### 4.1 整体材质气质
LingNote 的材质感必须像：
- 高级纸张
- 极轻玻璃感
- 现代知识工具

而不是：
- 厚重塑料感
- 旧式后台面板
- 过度拟物

### 4.2 卡片材质
卡片必须微悬浮、柔和、轻容器感。

推荐可使用轻量玻璃感，但必须非常克制，例如：
- `background: rgba(255,255,255,0.88)`
- `backdrop-filter: blur(8px)`
- `border: 1px solid rgba(255,255,255,0.4)`

但玻璃感只能轻微存在，禁止重度毛玻璃。

禁止：
- 强反射
- 高透明度
- 厚重玻璃拟态
- MacOS 控制中心式大面积玻璃效果

### 4.3 层级关系
层级必须通过材质差异表达，而不是靠夸张阴影。

层级顺序：
- 页面背景
- 卡片层
- 浮层 / Dialog
- Dropdown / Popover

---

## 5. 阴影系统

### 5.1 阴影哲学
阴影必须短、软、浅，不可显眼。

目标是：
- 让用户感受到层次
- 而不是看到“阴影本身”

### 5.2 卡片阴影
推荐：
- `0 1px 2px rgba(15,23,42,0.04)`
- `0 4px 12px rgba(15,23,42,0.03)`

### 5.3 Hover 阴影
hover 只允许轻微抬起和轻微阴影增强。

禁止：
- 大面积扩散阴影
- 发光
- 重投影
- 夸张浮起

---

## 6. 圆角系统

圆角必须统一，不可随意变化。

推荐：
- 小组件：`10px`
- 卡片：`16px`
- Dialog：`20px`

禁止：
- 过小圆角，显得老旧
- 过大圆角，显得轻浮

---

## 7. 间距系统

### 7.1 全局节奏
间距必须有统一节奏，推荐只使用这些尺度：

- 4
- 8
- 12
- 16
- 24
- 32
- 48

### 7.2 内容宽度
编辑区域不要过窄。

推荐内容宽度：
- `max-width: 860px`

### 7.3 呼吸感
页面元素之间必须有明显但克制的呼吸感。

禁止：
- 元素贴太近
- 卡片堆叠拥挤
- 组件过分密集
- 像传统管理后台那样压缩排版

---

## 8. 字体系统

### 8.1 字体栈
推荐字体：
- `Inter`
- `PingFang SC`
- `HarmonyOS Sans SC`
- `system-ui`
- `sans-serif`

### 8.2 字体层级
标题：
- `600-700`

正文：
- `400-500`

### 8.3 行高
正文行高：
- `1.6 - 1.8`

### 8.4 字体要求
- 简洁
- 现代
- 易读
- 不装饰化
- 不使用手写感字体
- 不使用过度艺术化字体

---

## 9. 按钮与输入框

### 9.1 按钮
按钮必须干净、明确、统一。

推荐按钮高度：
- `38px - 42px`

主按钮：
- 使用主强调色
- 文字清晰
- 状态反馈明确

次按钮：
- 弱化背景
- 不抢视觉

危险按钮：
- 低饱和警示色

禁止：
- 巨大厚重按钮
- 大面积蓝色填充失控
- 老式后台按钮样式

### 9.2 输入框
输入框必须柔和、边界清楚、聚焦明显。

focus 可使用轻量环形提示，例如：
- `box-shadow: 0 0 0 4px rgba(79,124,255,0.12)`

禁止：
- 强烈红框警报式错误
- 密集表单挤压
- 太粗的边框

---

## 10. 动画系统

### 10.1 动画定位
动画必须像空气流动，而不是机械弹跳。

### 10.2 时长
推荐：
- `120ms - 220ms`

不要超过：
- `300ms`

### 10.3 easing
推荐：
- `cubic-bezier(0.4, 0, 0.2, 1)`

### 10.4 允许的动画
只允许用于：
- hover
- 面板展开
- 弹窗出现
- 列表加载
- 内容切换
- 按钮反馈

### 10.5 禁止的动画
禁止：
- 夸张弹跳
- 旋转闪烁
- 复杂粒子效果
- 大幅漂移
- 过强缩放
- 过长转场

---

## 11. 图标与装饰

### 11.1 图标风格
图标必须使用统一线性风格。

要求：
- 简洁
- 轻巧
- 现代
- 视觉重量适中

### 11.2 装饰原则
装饰只能辅助理解，不得喧宾夺主。

禁止：
- 过度插图化
- 卡通化图标
- 夸张 3D 素材
- 无意义装饰块

---

## 12. 页面状态

### 12.1 空状态
空状态必须简洁、温和、有引导。

要求：
- 说明当前没有内容
- 给出下一步操作
- 不能显得冷冰冰

### 12.2 加载态
加载态应轻量、优雅。

推荐：
- 骨架屏
- 轻量 loading

禁止：
- 整页强阻塞式加载
- 夸张转圈动画

### 12.3 错误态
错误态必须清晰、克制、可恢复。

要求：
- 直接说明问题
- 给出恢复方式
- 不堆技术栈报错
- 不制造恐慌感

---

## 13. 页面级风格

### 13.1 笔记列表页
- 干净
- 排版整齐
- 信息密度适中
- 以标题、摘要、更新时间为主

### 13.2 编辑页
- 中心内容足够宽
- 编辑区域可专注
- 辅助面板弱化但可访问
- 不干扰输入体验

### 13.3 设置页
- 简洁
- 分组清晰
- 不要做成后台管理系统
- 不要做成表格堆砌页

---

## 14. 绝对禁止事项

AI 生成 UI 时，禁止以下内容：

1. 老旧后台管理系统风格
2. Bootstrap 风格模板
3. 旧式 Ant Design 后台风
4. 大量默认蓝色按钮 + 灰底布局
5. 大面积纯黑或纯白强对比
6. 强渐变、霓虹、发光
7. 重度玻璃拟态
8. 重阴影
9. 拥挤布局
10. 信息密度过高
11. 低质量 Dribbble 炫技风
12. 纯为了“高级感”而牺牲可读性

---

## 15. AI 生成 UI 时的决策顺序

AI 在生成任何页面时，必须按以下顺序判断：

1. 内容是否清晰
2. 层级是否明确
3. 间距是否舒适
4. 颜色是否统一
5. 材质是否轻盈
6. 动画是否克制
7. 体验是否顺滑

如果视觉和可读性冲突，必须优先可读性。

---

## 16. 最终视觉目标

LingNote 的 UI 应该像：
- 安静的工作室
- 现代的笔记空间
- 轻盈的知识容器
- 有呼吸感的内容编辑器

用户打开后应该感觉：

“这个产品很轻，很稳，很现代，而且它尊重内容。”
